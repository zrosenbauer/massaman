# isNotEmpty

Checks if a value is not empty. Complement of `isEmpty`.

```typescript
isNotEmpty('hello') // true
isNotEmpty([]) // false
```

## Usage

### `isNotEmpty(value: string | object)`

Checks if a value is not empty. Complement of `isEmpty`.

```typescript
import { isNotEmpty } from 'massaman'
// or:  import { isNotEmpty } from 'massaman/predicate'

isNotEmpty('hello') // true
isNotEmpty([]) // false
```
