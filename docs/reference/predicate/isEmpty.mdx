# isEmpty

Checks if a value is empty.

- Strings: `''`
- Arrays: `length === 0`
- Maps/Sets: `size === 0`
- Objects: no own enumerable keys

```typescript
isEmpty('') // true
isEmpty([]) // true
isEmpty({}) // true
isEmpty(new Map()) // true
```
