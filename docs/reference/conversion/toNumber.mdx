# toNumber

Converts a value to a number.

A thin wrapper over `Number(value)` for a consistent, function-based API
without calling the global constructor directly.

```typescript
toNumber('42') // 42
toNumber(null) // 0
```

## Usage

### `toNumber(value: unknown)`

Converts a value to a number.

A thin wrapper over `Number(value)` for a consistent, function-based API
without calling the global constructor directly.

```typescript
import { toNumber } from 'massaman'
// or:  import { toNumber } from 'massaman/conversion'

toNumber('42') // 42
toNumber(null) // 0
```
