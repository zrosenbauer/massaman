# toBoolean

Converts a value to a boolean.

A thin wrapper over `Boolean(value)` for a consistent, function-based API
without calling the global constructor directly.

```typescript
toBoolean(1) // true
toBoolean(0) // false
toBoolean('') // false
```

## Usage

### `toBoolean(value: unknown)`

Converts a value to a boolean.

