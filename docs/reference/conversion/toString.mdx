# toString

Converts a value to a string.

A thin wrapper over `String(value)` for a consistent, function-based API
without calling the global constructor directly.

```typescript
toString(42) // '42'
toString(null) // 'null'
```

## Usage

### `toString(value: unknown)`

Converts a value to a string.

A thin wrapper over `String(value)` for a consistent, function-based API
without calling the global constructor directly.

```typescript
import { toString } from 'massaman'
// or:  import { toString } from 'massaman/conversion'

toString(42) // '42'
toString(null) // 'null'
```
