# toString

Converts a value to a string.

Thin wrapper over `String(value)` — kept as a stable surface against
future global-constructor changes.

```typescript
toString(42) // '42'
toString(null) // 'null'
```

## Usage

### `toString(value: unknown)`

Converts a value to a string.
