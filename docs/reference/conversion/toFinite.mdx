# toFinite

Converts a value to a finite number.

Returns `0` for non-finite results (`NaN`, `Infinity`, `-Infinity`).

```typescript
toFinite('3.14') // 3.14
toFinite(Infinity) // 0
```

## Usage

### `toFinite(value: unknown)`

Converts a value to a finite number.

Returns `0` for non-finite results (`NaN`, `Infinity`, `-Infinity`).

```typescript
import { toFinite } from 'massaman'
// or:  import { toFinite } from 'massaman/conversion'

toFinite('3.14') // 3.14
toFinite(Infinity) // 0
```
